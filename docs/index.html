Where the money goes

We measured before building more features.

We expected read dedup to be the big win. On real transcripts, Claude almost never re-reads an unchanged file. The cost is the context itself, paid again on every request.

~60%

of a long session is cache reads

Cache reads are cheap per token, but every token in context is read again on every later request. 280K of context × 300 requests adds up.

40×

Opus 5.5 vs Haiku 5.5 per token

$4.00 against $0.10 per million input tokens. Reading files and test logs doesn't need the expensive model.

1×

a subagent's reading is paid once

Its context is thrown away when it returns. Only the short answer enters yours, and only that gets re-read.

Works where you work

Chat, Cowork and Claude Code each get something useful.

Most installs come from claude.ai chat, where a plugin loads its skills but not hooks or local scripts. So the plugin ships skills that work everywhere, and the heavy machinery where it can run.

/cco audit

Does it save you anything? Ask your transcripts.

Claude Code keeps every session in ~/.claude/projects/. The audit prices them with each session's real model and cache TTL, counts every refusal CCO made, and ranks the levers that would save you the most. Nothing leaves your machine.

Everything else it does

Quiet by default. Every message actually arrives.

Since v4.20 the hooks answer in the JSON Claude Code reads: advice for Claude as context, notes for you as a system message that costs no tokens.

meter

A live line under the prompt

Context fill, session cost, 5-hour and weekly limits, and minutes until the prompt cache goes cold. One toast when something needs you. /cco-meter hides it.

read-cache

Read dedup with file maps

An unchanged re-read is skipped and replaced by a map of the file. Per subagent, and it steps aside if Claude asks again.

budget

Budget and cache-break warnings

Real context size from the transcript, the cost of a cold cache after a pause, and a nudge to /compact before quality drops.

/cco

One command for the rest

/cco is the session board; /cco help lists audit, task, pack, orchestrate, config and the others.

/cco task

Task state that survives /compact

A small JSON state per task, put back into context after compaction or resume.

/cco overhead

Fixed overhead audit

What every session pays before you type: system prompt, MCP tools, CLAUDE.md. Lists MCP servers you never call.

.contextignore

Files you never need

Block lock files and build output from Read. ContextShield proposes rules from your own waste history.

How we keep it honest

Numbers we can defend.

✓

Transcripts over estimates. Cost comes from the API usage Claude Code records, priced per model, cache TTL and fast mode.

✓

NET savings. Everything CCO injects into context is subtracted from what it claims to save.

✓

Tested the way Claude Code runs it. End-to-end tests drive the real hooks through sh -c on Linux and macOS; /cco doctor does the same on your machine.

✓

Local only. The plugin's code makes no network calls. Data lives in ~/.claude-context-optimizer/ and is pruned automatically.

Install

Two commands. Then restart Claude Code.

Install
claude plugin marketplace add egorfedorov/claude-context-optimizer
claude plugin install context-optimizer@cco
Check it, then see your numbers
# in Claude Code
/cco doctor
/cco audit

On claude.ai, the desktop app or Cowork: open the Directory and add Context Optimizer. Upgrading from 4.x: commands moved under /cco (/cco-audit is now /cco audit). Turn the delegation policy off with "orchestrate": false in ~/.claude-context-optimizer/config.json.
